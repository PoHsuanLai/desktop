# Release notes

The notes for the release being prepared, in plain words for the person who updates. Copy the list under
"Next release" into the release's notes (`release/README.md`, "Cutting a release"), then move it under the
version once it is out. Notes are plain text, at most 16 KiB.

## Next release

- Programs that watch the screen, type for you or read the clipboard now ask the first time; a program that exits before you answer (wtype) works the next time you run it.
- If a program changes your displays, you're asked whether to keep the new settings; they go back after 15 seconds unless you keep them.
